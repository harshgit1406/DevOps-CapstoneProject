# Project Objectives

- Start the complete platform with two commands and no paid service.
- Test and scan every change before publishing an image.
- Deploy two hardened replicas with probes, rolling updates, HPA, recovery, and rollback.
- Collect real request, latency, error, CPU, memory, uptime, and availability metrics.
- Demonstrate scaling, self-healing, Terraform, security scanning, and monitoring reproducibly.
