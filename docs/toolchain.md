# Toolchain Explanation

Git/GitHub preserve change history; Actions automates delivery; Pytest checks behavior; Semgrep/Gitleaks scan source and secrets; Trivy scans images; Checkov/Kubescape scan infrastructure; Docker packages the runtime; Kind provides local Kubernetes; Helm manages releases; Terraform records local infrastructure declaratively; Prometheus/Grafana provide observability. SonarQube remains optional to protect laptop resources.
